# Audit remediation status — 4 October 2026

This document records the remediation of findings F-01 through F-07 from the source-tree audit report at `audit-reports/REPOSITORY_AUDIT_REPORT.md`. That audit report is retained as historical evidence and is not edited by this remediation. This page is the current status record; it does not certify release readiness.

The remediation handoff used version **0.4.9**. The subsequent **0.5.0** About feature has its own [dated validation record](validation-2026-10-04.md); the remediation evidence below remains historical. A fresh, hash-verified 109-file corresponding-source/bootstrap official build passed; the input comparison is `out/validation/audit-remediation-20261004/clean-build-input-comparison-0.4.9.json`. Standard validation passed all 19 groups with exit 0 in `out/validation/0.4.9-20261004T133857640Z/summary.json`, ending at `2026-10-04T13:40:24.5776569Z`. The user chose to keep WebView2 and leave the 150 MiB active-memory gate open while handing off the other fixes. The experimental `--disable-gpu` path remains removed under Microsoft shipping-flag guidance; the supported WebView2 InPrivate investigation found no justified shipping change or demonstrated memory benefit, so no shipping configuration change was made.
